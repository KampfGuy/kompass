# KampfScript — complete reference for AI assistants

> Paste this whole document into an AI assistant before asking it to write KampfScript (.ks) for Kompass 1.5.3.
> Generated by tools/gen-ai-doc.js from the real interpreter (src/lang.js) and host (src/host.js); example outputs were produced by running them.

## 0. Rules for the assistant (read first)

- KampfScript is NOT JavaScript or Python. Use ONLY the syntax and built-ins listed here. There are no classes, imports, try/catch, ternaries, `++`, `&&`/`||`, template strings, or methods (`s.length` is wrong — use `len(s)`).
- Blocks ALWAYS need braces: `if x { ... }`, `while c { ... }`, `for v in xs { ... }`, `fn f(a) { ... }`.
- `range(a, b)` excludes b. `+` with any string concatenates. Missing map keys read as `nil`. Errors stop the program.
- Output only KampfScript code when asked for a program; comments start with `#` or `//`.

## 1. Lexical structure

- Statements end at a newline or `;`. Newlines inside `( )` and `[ ]` are ignored (multi-line calls/lists are fine); inside `{ }` blocks and maps they separate entries.
- Comments: `# ...` or `// ...` to end of line.
- Numbers: `42`, `3.14`, `.5` (all numbers are floats; integers print without `.0`).
- Strings: `"..."` or `'...'`, single line, escapes `\n \t \\ \" \'`. Strings can be indexed: `s[0]`, `s[-1]`.
- Template strings (v1.3): `` `Hi {name}, next year {age + 1}` `` — backticks, any expression inside `{ }`, `\{` for a literal brace; may span lines.
- Numbers may use exponents (v1.3): `1e6`, `2.5e-3`. Constants: `PI` `TAU` `E` `INFINITY` (PI = 3.14159…, TAU = 2·PI).
- Identifiers: `[A-Za-z_][A-Za-z0-9_]*`.
- Keywords (16): `let` `fn` `return` `if` `else` `while` `for` `in` `break` `continue` `true` `false` `nil` `and` `or` `not`

## 2. Grammar (EBNF)

```ebnf
program    = { statement NL } ;
statement  = "let" IDENT "=" expr
           | "fn" IDENT "(" [ IDENT { "," IDENT } ] ")" block
           | "if" expr block { "else" "if" expr block } [ "else" block ]
           | "while" expr block
           | "for" IDENT [ "," IDENT ] "in" expr block   (* for i, item in list / for key, value in map *)
           | "return" [ expr ] | "break" | "continue"
           | target ( "=" | "+=" | "-=" | "*=" | "/=" | "%=" ) expr
           | expr ;
target     = IDENT | postfix "[" expr "]" | postfix "." IDENT ;
block      = "{" { statement NL } "}" ;           (* braces are mandatory *)
expr       = or ;  or = and { "or" and } ;  and = not { "and" not } ;
not        = ( "not" | "!" ) not | cmp ;
cmp        = add [ ( "==" | "!=" | "<" | ">" | "<=" | ">=" ) add ] ;
add        = mul { ( "+" | "-" ) mul } ;  mul = unary { ( "*" | "/" | "%" ) unary } ;
unary      = "-" unary | postfix ;
postfix    = primary { "(" [ args ] ")" | "[" expr "]" | "." IDENT } ;
primary    = NUMBER | STRING | TEMPLATE | "true" | "false" | "nil" | IDENT
           | "fn" "(" params ")" block                (* anonymous function *)
           | "(" expr ")" | "[" [ expr { "," expr } ] "]"
           | "{" [ key ":" expr { "," key ":" expr } ] "}" ;   key = IDENT | STRING | NUMBER
```

`else` may sit on the line after `}`. Comparisons do not chain (`a < b < c` is an error-prone non-idiom).

## 3. Types and values

| type() | literal | notes |
|---|---|---|
| `nil` | `nil` | absence; missing map keys, functions without return |
| `bool` | `true` `false` | |
| `number` | `1` `2.5` | double precision; `/` is float division |
| `string` | `"hi"` | immutable; index with `s[i]` |
| `list` | `[1, "a"]` | mutable, ordered, negative indexes from the end |
| `map` | `{a: 1, "b c": 2}` | string keys, insertion ordered, `m.a` or `m["a"]` |
| `function` | `fn(x) { ... }` | first-class, closures |
| UI handle | from `box()`, `button()` ... | `type()` gives the kind, e.g. "button" |

**Truthiness:** `false`, `nil`, `0` and `""` are falsy. EVERYTHING else is truthy — including `[]` and `{}`.

**Equality:** `==` is strict (no coercion: `1 == "1"` is false). Lists compare by content; maps only by identity (`{} == {}` is false).

## 4. Operators

| op | meaning |
|---|---|
| `+` | number add; if EITHER side is a string → text concatenation (`"a" + 1` = `"a1"`); list + list = concatenation |
| `- * /` | numbers only; `"ab" * 3` = `"ababab"` |
| `%` | modulo, result has the sign of the divisor (`-7 % 3` = 2) |
| `== !=` | strict equality |
| `< > <= >=` | numbers with numbers, or strings with strings |
| `and or` | short-circuit, return an operand (`x or "default"` works) |
| `not` / `!` | boolean negation |
| `= += -= *= /=` | assignment statements (not expressions) |

Division or modulo by zero is an error. Precedence (low→high): or, and, not, comparison, + -, * / %, unary -, call/index/field.

## 5. Variables, scope, functions

- `let x = v` declares in the CURRENT block scope. Every `{ }` block (if/while/for/function body) is a new scope.
- `x = v` assigns to the nearest existing `x`; if none exists it creates `x` in the current scope (prefer `let`).
- `for v in xs` makes a fresh `v` per iteration, so closures capture each value correctly.
- `for` iterates lists, strings (characters), maps (keys) and numbers (`for i in 3` → 0, 1, 2). With two names: `for i, x in list` (index, item), `for k, v in map` (key, value).
- `fn name(a, b) { ... }` defines a function in the current scope (call it before or after, as long as the definition ran). Missing arguments are `nil`; extra arguments are an error.
- Functions are closures. Max recursion depth 200. No default/keyword/variadic parameters.
- Programs are step-metered: ~2,000,000 steps per run or callback in browser.ks, 200,000 in sandboxes/pages. Infinite loops stop with "Step limit reached".

## 6. Errors

- Any error stops the current program/callback with `Line N: message`. There is NO try/catch; guard with `if` checks instead (e.g. `if has(m, "k")`, `if num(s) != nil`).
- Errors try to help: typos suggest the closest name (`pirnt` → did you mean print?), `s.length` says use len(s), `x++` says write x += 1, `&&` says use and.
- `error("msg")` raises your own error. Common errors: Unknown name, index out of range, Can't add list and number, X expects N arguments.

### 7.7 Making games & apps (v1.3)

Pages and lesson stages can draw on a `canvas`, run an `on_frame` game loop, read `key_down` / `on_keypress` / `on_mouse`, build controls with `slider` / `checkbox` / `dropdown`, and remember things with `store_get` / `store_set`. Frame loops, timers and key handlers stop automatically when the page is closed. Canvases are double-buffered, so a frame never shows half-drawn. Colours: `"#ff4500"`, `"rgba(0,0,0,0.5)"`, names like `"white"`, or a LIST for a gradient: `["#333", "#999", "#333"]` (left→right) / `["down", top, bottom]`. Setstyle also accepts layout properties (position, left, top, z-index, display, overflow, transform…) so pages can float panels over a canvas. The full Spaceflight Sim (`resources/spaceflight.ks`, open `kompass://spaceflight`) is a ~2000-line example.

```ks
let c = canvas(body(), 320, 160)
let ball = {x: 40, y: 40, vx: 120, vy: 90}
on_frame(fn(dt) {
  if key_down("space") { ball.vy -= 300 * dt }
  ball.x += ball.vx * dt
  ball.y += ball.vy * dt
  if ball.x < 10 or ball.x > 310 { ball.vx = -ball.vx }
  if ball.y < 10 or ball.y > 150 { ball.vy = -ball.vy }
  draw_clear(c, "#141414")
  draw_circle(c, ball.x, ball.y, 10, "#ff4500")
  draw_text(c, 10, 14, `x = {round(ball.x)}`, "white", 12)
})
```

### 7.8 3D games (44, v1.5.2) — everywhere the UI built-ins work, including pages and Kugel Store games

Real 3D with WebGL (three.js is bundled inside Kompass, nothing is downloaded). y is up, the camera looks toward -z at yaw 0, sizes are metres, ALL ANGLES ARE DEGREES. Shapes start at (0, 0, 0), centred. Animate objects in `on_frame(fn(dt) {...})`; the scene redraws itself every frame and is cleaned up when the page closes. Put a HUD on top with normal UI built-ins using the scene as parent (`label(s, "Score")`, `canvas(s, 150, 150)` + `setstyle(x, "position", "absolute")`). Examples: `kompass://maze3d` (resources/maze3d.ks, first-person) and `kompass://runner3d` (resources/runner3d.ks, third-person); `kompass://games3d` lists them.

```ks
let s = scene3d(body())
sky3d(s, "#87ceeb", "#ffffff")
let ground = plane(s, 40, 40, "#3a7d44")
look3d(ground, {texture: "grid", repeat: 20})
let wall = cube(s, 10, 2, 0.5, "#b5653f")
move3d(wall, 0, 1, -6)
solid3d(wall)
let goals = []
for i in range(5) {
  let g = cube(s, 0.6, 0.6, 0.6, "#ffd23f")
  look3d(g, {glow: "#664400"})
  move3d(g, i * 3 - 6, 1, -10)
  push(goals, g)
}
let hud = label(s, "")
camera3d(s, 0, 1.6, 4)
fps_controls(s, {speed: 5})
let score = 0
on_frame(fn(dt) {
  let me = camera_get(s)
  let keep = []
  for g in goals {
    spin3d(g, 0, 90 * dt, 0)
    if dist3d(g, me) < 1 {
      remove3d(g)
      score += 1
    } else { push(keep, g) }
  }
  goals = keep
  settext(hud, `Score: {score}`)
  let pad = gamepad()
  if pad.connected and pad.a { print("A pressed") }
})
```

## 8. Kompass architecture

- Kompass is an Electron app. `src/main.js` (main process) owns windows, files, the ad blocker, the password vault and context menus. `src/host.js` (renderer) runs `browser.ks` with the KampfScript interpreter and implements the native built-ins above. Web pages run in sandboxed Chromium `<webview>`s.
- **browser.ks is the whole browser UI**: tab strip, toolbar, bookmarks, internal pages (`kompass://home`, `search`, `history`, `bookmarks`, `settings`, `about`, `learn`, `learn/ai`, `builder`, `passwords`, `page/<name>`), shortcuts. Users edit it with Ctrl+Shift+K → "★ browser.ks"; Settings → Reset restores the shipped one.
- Data is saved with `save_data(name, value)` as JSON in the profile (`settings`, `bookmarks`, `history`, `learn_progress`, `builder`).
- Events: `on_tab_event(fn(ev, id, value))` with ev = `url`, `title`, `loading` (bool), `favicon`, `visit`, `error`, `state`, `internal` (draw an internal page into `tab_page(id)`), `popup` (a page asked for a new window; id 0). Also `on_key`, `on_double_right_click`, `on_password_offer`, `on_vault_lock`, `after`, `every`, and UI callbacks (`on_click`, `on_input`, button fns).
- Callbacks run one at a time; async built-ins (kugel_search, run_page, save_text_file...) simply wait — no promises/await in the language.
- **Your own pages**: save `scripts/NAME.ks` in the ⚡ editor (📄 New page creates a starter) and open `kompass://page/NAME`; it runs isolated with the UI + page API. From an editor script, `page_new("Title")` opens a new tab and returns a box to draw into.
- **Builder pages**: `kompass://builder` edits KampfScript programs that draw a search home page via `run_page`. "Set as my home page" stores its name in `settings.home_ks`; `kompass://home` then runs it (Restore default clears it).

## 10. Gotchas

- `range(1, 5)` is `[1, 2, 3, 4]` — the end is EXCLUSIVE. `random(1, 6)` is INCLUSIVE.
- `"Total: " + 1 + 2` is `"Total: 12"`; write `"Total: " + (1 + 2)`.
- Braces are required even for one statement. No `elif` — write `else if`.
- In templates `{` starts an expression: write `\{` for a literal brace. Plain "..." strings never interpolate.
- No try/catch, no exceptions to catch. Validate first.
- `[]` and `{}` are truthy; test `len(xs) == 0`.
- No methods or properties on strings/lists: `len(x)`, `upper(s)`, `push(xs, v)`. Only maps have `.field` — so a map can hold functions: `ship.update = fn() {...}` then `ship.update()`.
- `sort`, `reverse`, `slice`, `map`, `filter` return NEW lists; `push`, `pop`, `insert`, `remove` mutate.
- `replace` replaces ALL occurrences. `split(s)` splits on a single space.
- Assignments are statements: `if (x = 3)` is invalid. `x++` does not exist: use `x += 1`.
- In builder pages use `search(text)`, not tab built-ins; `setstyle` only accepts properties from `css_props()` and rejects `url(...)`.
